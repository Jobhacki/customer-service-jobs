# Contributing to the Customer service and support jobs list

Help service professionals find roles that match how they work with customers. Please use the employer's own posting when suggesting an opening.

## What belongs in this list

Customer support, customer service, technical support, and customer success roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, and whether the work is support, service, or customer success.

[Open the Add a job form](https://github.com/Jobhacki/customer-service-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the service role title, employer, link, and whether the page is missing or says the role is filled.

[Open the Report a dead link form](https://github.com/Jobhacki/customer-service-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
